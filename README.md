# Нур — время для главного

Мобильное PWA с визуальным направлением Apple TV: фотография мечети, спокойные зелёные оттенки, крупные цифры и плавающая навигация с Liquid Glass.

**[Открыть приложение](https://noor-prayer-companion.genialdegu129.chatgpt.site/)**

Адрес [GitHub Pages](https://maga17mm-hub.github.io/noor-prayer-pwa/) автоматически открывает ту же рабочую PWA. В Pages публикуется только папка `docs/`; серверное приложение и API уведомлений работают на Sites/Cloudflare. В настройках Pages выбран источник `main` → `/docs`. Не переключайте источник на корень репозитория: при отсутствии входной HTML-страницы Jekyll показывает README.

## Возможности

- Намаз по GPS или выбранному городу; поиск городов, ручные координаты, IANA timezone и переход по датам. Расчёт Adhan выполняется на устройстве и работает офлайн.
- Семь методов расчёта, выбор времени Асра по мазхабу, поправка ±30 минут. Для высоких широт — правило 1/7 ночи. При отсутствии астрономического решения время не выдумывается.
- Полный Коран: 114 сур, 6236 аятов, русский перевод смыслов Эльмира Кулиева. Поиск, закладки, сохранение места чтения, аудио Мишари аль-Афаси.
- Два режима: арабский текст с переводом по аятам и 604 подлинные каллиграфические страницы Мединского мусхафа. В первой и второй SVG-страницах обрезаны только внешние пустые поля; ни текст, ни расположение аятов не менялись.
- Три отдельные упорядоченные подборки азкаров. Утро и вечер начинаются с собственных полных формул. После намаза — истигфар, салям, единобожие,33/33/33 и завершение, аят аль-Курси и три короткие суры. Повторение коротких сур меняется с1 на3 после Фаджра/Магриба. Счётчики раздельны по дате, группе и выбранному намазу.
- Кибла: геодезический азимут, расстояние до Каабы, датчик абсолютной ориентации с запросом разрешения и карта. При отсутствии датчика явно показано направление от истинного севера. Магнитное склонение датчика не корректируется.
- Установка на главный экран iOS/Android, offline app shell, локальные настройки, сохранение всего текста и перевода, кеширование прочитанных страниц мусхафа.
- Настоящий зашифрованный Web Push через сервер Cloudflare Worker и D1. Подписки принадлежат пользователю; повторная доставка одного события защищена уникальным ключом.
- Напоминания за 0/5/10/15 минут, выбор намазов, серверный тест push, отключение подписки и календарь с сигналами на 30 дней.

## Запуск

Нужен Node.js 24 или новее.

```sh
npm ci
npm run dev
```

Приложение откроется на `http://127.0.0.1:5173`. Service Worker устанавливается только в production-сборке, чтобы не кешировать HMR-модули.

```sh
npm run typecheck
npm test
npm run build
npm start
```

База для локального push API создаётся после первой сборки:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_busy_killraven.sql
```

## Уведомления и эксплуатация

На iPhone требуется iOS 16.4+, установка PWA на главный экран и разрешение на уведомления из установленного приложения. На реальном устройстве необходимо нажать «Проверить» и подтвердить доставку: браузерная проверка на компьютере не заменяет испытание на iPhone.

В D1 сервер создаёт и сохраняет VAPID-ключи один раз. Приватный ключ никогда не передаётся клиенту. Тело push шифрует `web-push` (aes128gcm). Разрешены только endpoint-домены браузерных push-служб, запросы с произвольными URL отклоняются. После 404/410 от push-службы подписка удаляется; неактивные подписки удаляются спустя 90 дней.

`.github/workflows/prayer-push.yml` запускает серверную проверку через GitHub Actions и хранит служебный доступ только в Actions Secrets `NOOR_SITE_URL` и `NOOR_SITES_TOKEN`. Эти секреты не должны попадать в Git. Каждый запуск проверяет наступившие события с интервалом 20 секунд около 5 минут. GitHub может задерживать scheduled runs; ОС и push-службы тоже не дают гарантии доставки строго в секунду. Последний heartbeat виден в `/api/push/status`. При отсутствии активности в публичном репозитории GitHub может приостановить cron.

Для эксплуатации с требованием доставки близко к заданной минуте рекомендуется выделенный планировщик. Worker уже экспортирует `scheduled()`; при самостоятельном развёртывании в своём Cloudflare аккаунте можно подключить Cron Trigger `* * * * *` и убрать GitHub workflow. Не подключайте одновременно разные ключи VAPID для той же подписки.

Текущий Sites-сайт закрыт для владельца. `/api/push/dispatch` защищён этой границей и служебным доступом Sites. **Перед переводом сайта в публичный режим обязательно добавьте отдельную серверную авторизацию cron endpoint**; нельзя выставлять его публично в текущей конфигурации. API подписки требует подписанного идентификатора пользователя Sites, проверяет Origin и владельца. Для публичной версии также потребуется отдельное решение идентификации пользователей.

Расписание календаря привязано к выбранным координатам и настройкам на момент экспорта. При переезде или изменении метода импортируйте новый календарь и удалите старый в календарном приложении. Для регионального расписания сверьте метод, мазхаб и поправки с местной мечетью.

## Данные и приватность

Без рекламы, трекеров и аналитики. Место, закладки и оформление хранятся в localStorage устройства. Запросы поиска города идут в Open-Meteo, определения часового пояса GPS — в Aladhan. При включении Web Push координаты и метод расчёта сохраняются на сервере, поскольку напоминания рассчитываются без открытого браузера. Отключение push удаляет подписку.

Первое открытие новой каллиграфической страницы и аудио требует интернета. Полный арабский текст и перевод можно отдельно сохранить кнопкой «Читать офлайн». Первая и вторая страницы включены в приложение. Исходный текст Корана сохранён без изменений.

## Дизайн и источники

- [Apple TV / Refero](https://refero.design/apps/search?app_id%5Bid%5D%5B%5D=130) — композиция и визуальная иерархия.
- [Liquid Glass Studio](https://liquid-glass-studio.vercel.app/) и [исходный код](https://github.com/iyinchao/liquid-glass-studio) — изучение физики материала. В приложении используются исходные WebGL2-рендерер и оптические GLSL-шейдеры этого проекта: background → vertical blur → horizontal blur → refraction/dispersion/Fresnel/glare. Оптический preset соответствует демонстрации (толщина20, расстояние0.05, n1.4, дисперсия7, blur1, tint alpha0). Текстура — снимок настоящего DOM-подложки без стеклянных элементов, обновляемый при прокрутке и изменениях. Только выходная альфа маскируется для композиции с DOM, а форма и размер задаются границами контрола. Файлы upstream и их SHA256 перечислены в `lib/liquid-glass-studio/UPSTREAM.json`. WebGL2 работает и в Safari; простой fallback включается только если GPU/необходимое расширение недоступны либо пользователь уменьшил эффекты.
- [Adhan JS](https://github.com/batoulapps/adhan-js) — астрономические вычисления.
- [Al Quran Cloud](https://alquran.cloud/api) / [Tanzil](https://tanzil.net) — Quran Uthmani и `ru.kuliev`.
- [Batoul Apps Quran SVG](https://github.com/batoulapps/quran-svg) — 604 страницы, MIT.
- [Amiri Quran](https://github.com/aliftype/amiri) — шрифт, SIL Open Font License.
- [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) и [Aladhan](https://aladhan.com/prayer-times-api) — города и часовые пояса.
- [Unsplash](https://images.unsplash.com/photo-1519817650390-64a93db51149) — фотография мечети; [лицензия](https://unsplash.com/license).

Исходный код приложения — MIT. Тексты, перевод, шрифты и сторонние ресурсы сохраняют собственные условия. См. `THIRD_PARTY_NOTICES.md` и лицензии в `public/`.
